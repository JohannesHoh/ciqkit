# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
adopted by reference. Its standards apply in all project spaces: issues, pull
requests, discussions and any other place where someone represents the project.

## Enforcement

Report unacceptable behaviour privately to the maintainer through GitHub: use
the repository's **Security** tab and choose **Report a vulnerability** (private
reporting), or contact the maintainer via their GitHub profile. Please do not
post reports in public issues. Reports are handled by the maintainer, kept
confidential, and answered as promptly as a one-person spare-time project
allows. Enforcement follows the
[Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
